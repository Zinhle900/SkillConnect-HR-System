SKILLCONNECT  is a Java EE-based HR screening system designed to help Human Resources teams efficiently evaluate candidates. The system allows applicants to submit their profiles, which are then assessed based on skills, programming languages, projects, certifications, and experience to support better hiring decisions.

##Features
Candidate profile submission
Automated skills-based evaluation
Captures programming/coding languages, projects, and certifications
HR dashboard for reviewing applicants
Structured decision support for recruitment

##Technologies Used
Java EE (Servlets, JSP, EJB)
HTML/CSS/JavaScript
NetBeans IDE
GlassFish / Tomcat Server
MySQL (if applicable)

##System Purpose
The system is designed to streamline the recruitment process by reducing manual CV screening and improving the accuracy of candidate evaluation through structured criteria-based assessment.
